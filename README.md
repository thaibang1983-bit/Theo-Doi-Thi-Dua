📊 Tra cứu dữ liệu Google Sheets
Trang web tĩnh (index.html) hỗ trợ xem và tra cứu nhanh thông tin từ Google Sheets trực tiếp trên điện thoại và máy tính thông qua GitHub Pages.
✨ Tính năng chính
Kết nối & lưu link cục bộ: Dán link Google Sheets công khai để tải dữ liệu, tự động hỏi lưu trên thiết bị hiện tại và ẩn gọn khung nhập link sau khi tải xong.
Tìm kiếm chuẩn xác: Tìm đúng từ khóa hoặc họ tên đã nhập (hỗ trợ không phân biệt dấu tiếng Việt, khớp tuyệt đối toàn bộ ô), hiển thị kết quả ở khu vực thẻ riêng biệt tách khỏi bảng gốc.
Giữ nguyên bảng tổng hợp: Hiển thị đầy đủ cấu trúc bảng Excel gốc, tự động thu gọn các cột nhiều chữ để xem được nhiều dòng hơn; chạm vào từng dòng để xem chi tiết.
Xuất dữ liệu: Hỗ trợ tải xuống kết quả tìm kiếm hoặc toàn bộ bảng dưới dạng tệp .csv.
🚀 Hướng dẫn sử dụng
1. Mở trang web qua đường dẫn GitHub Pages (https://thaibang1983-bit.github.io/Theo-Doi-Thi-Dua/).
2. Đảm bảo tệp Google Sheets đã bật quyền chia sẻ Bất kỳ ai có đường liên kết → Người xem.
3. Dán link Google Sheets vào ô nhập, bấm Tải dữ liệu và chọn OK (Lưu link) nếu muốn lưu trên máy.
4. Nhập họ tên hoặc thông tin cần tra cứu vào ô tìm kiếm và bấm Tìm kiếm.
